# 알파킹 캐릭터 소재

- 파일: `alpharking-poses.png` (투명 배경, 대기·인사 두 포즈)
- 제작: 내장 image_gen 도구. 사용자 제공 alpharking1.png를 캐릭터 참고 이미지로 사용.
- 프롬프트 요약: 참고 이미지와 비슷한 흰색 알파카, 파란 A 모자, 분홍 귀와 볼, 갈색 발굽의 부드러운 2D 일러스트. 동일 크기의 정면 대기와 앞발을 든 인사 포즈를 좌우 배치. 배경·추가 문구 없이 실제 알파 투명도 유지.
- CSS에서 배경 위치로 대기·인사 포즈를 선택합니다. 프레임별 손 흔들기나 눈 깜빡임 애니메이션은 포함하지 않습니다.

## 걷기 소재

- 파일: `alpharking-walk.png` (4열 × 2행, 투명 배경)
- 내장 image_gen 도구에 기존 알파킹 이미지를 참고로 제공하여 제작했습니다.
- 프롬프트: 동일한 흰 털·파란 A 모자의 캐릭터를 유지하고 위 행에는 왼쪽, 아래 행에는 오른쪽을 보는 걷기 4프레임을 배치. 발과 앞발을 번갈아 움직이고 모자의 A는 반전하지 않음. 동일 크기와 기준선, 투명 배경, 별도 문구 없음.
- CSS steps 애니메이션으로 걷기 프레임을 전환합니다. 이동 경로의 정지 구간에는 기존 대기 포즈를 표시합니다.

## 자동차 이동 소재

- 파일: `alpharking-car.png` (좌우 운전 포즈, 투명 배경). 현재 이동에는 이 파일을 사용합니다.
- 내장 image_gen 도구로 기존 알파킹을 참고해 제작했습니다.
- 프롬프트: 흰 털과 파란 A 모자의 알파킹이 작은 파란 오픈카를 운전하는 좌우 두 포즈. 모자의 A는 반전하지 않고, 전체 자동차와 귀·바퀴가 보이도록 하며 배경·도로·추가 문구 없이 투명하게 제작.
- 정지 시 대기 포즈, 마우스·키보드 포커스 시 인사 포즈로 전환합니다. 바퀴 회전 프레임은 포함하지 않습니다.

## 수면 표정

- 파일: `alpharking-sleep.png` (단일 투명 배경 이미지).
- 내장 image_gen 도구로 기존 알파킹의 흰 털·파란 A 모자를 참고해 제작했습니다.
- 프롬프트: 기존 대기 포즈와 같은 전신 비율과 색상을 유지하고, 눈을 부드럽게 감고 작은 입을 다문 편안한 수면 표정. 배경·소품·문구 없이 정면으로 서 있는 단일 캐릭터.
- 30초 무조작 졸기 상태에 표시하며 클릭·키 입력으로 깨어납니다.
